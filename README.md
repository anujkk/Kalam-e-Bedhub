# कलाम-ए-बेढब • کلامِ بیڈھب

> **The digital web archive of *Kalam-e-Bedhab*, presenting the poetry of Brij Kishore Narayan 'Bedhab' Gayawi in both Hindi (Devanagari) and Urdu (Nastaliq) scripts. This repository contains code for official website showcasing Kalam-e-Bedhab, a curated collection of Urdu shayari and poetry by Brij Kishore Narayan 'Bedhab' (Gaya, Bihar).**

Official website: https://anujkk.github.io/Kalam-e-Bedhub/

## 📖 Overview

**Kalam-e-Bedhab** is an online, open-access reading edition of the poetry collection by **Brij Kishore Narayan ‘Bedhab’ Gayawi** (1885–1958). Originally compiled from scattered works and published in December 1983 with financial assistance from the Bihar Urdu Academy, this website brings the complete work into an accessible digital format for readers worldwide.

To ensure anyone can comfortably read and enjoy his work, the entire collection is offered in two dual web presentations:
* **हिन्दी संस्करण (Devanagari script):** Specially transliterated/adapted for Hindi readers.
* **اردو ایڈیشن (Urdu / Nastaliq script):** Preserving the original script and poetic formatting.

---

## ✍️ About the Poet (शायर का परिचय)

* **Name:** Brij Kishore Narayan ‘Bedhab’ Gayawi (बृज किशोर नारायण ‘बेढब’ गयावी / برج کشور نارائن ‘بیڈھب’ گیاوی)
* **Lifespan:** 1885 – July 3, 1958
* **Origins:** Born in Amawan (Patna district), later settling in Gaya, Bihar.
* **Background:** A distinguished practicing advocate in Gaya from 1917 onwards. He developed a passion for poetry alongside his legal practice and became a regular figure in Gaya’s monthly *mushairas* around 1929–1930. He is remembered as an honest, open-hearted, and genial personality.

---

## 📚 About the Book & Poetry

* **Original Compiler:** Compiled and edited across years of research by the poet's grandson, **Ravindra Kumar Ravi**.
* **First Edition:** December 1983, published with the support of the **Bihar Urdu Academy**.
* **Genres Included:** *Ghazals* (ग़ज़लें), *Nazms* (नज़्में), *Qit'aat* (क़ितआत), *Rubaiyat* (रुबाइयात), and miscellaneous couplets (*Mutafarriq Ash'aar* / मुतफ़र्रिक़ अशआर), alongside introductory essays and biographical prefaces.
* **Tone & Themes:** While versatile, much of Bedhab's poetry is renowned for its **satirical, humorous, and light-hearted tone (हास्य-व्यंग्य / طنز و مزاح)**—poking gentle fun at courtrooms and legal bureaucracy (*kachahari*), evolving social fashions, festival celebrations (like Holi), and everyday life.

## ✨ Website Features

* **Bilingual Experience:** Seamless navigation between Hindi (Devanagari) and Urdu (Nastaliq) editions.
* **Typographic Care:** Uses tailored web fonts (`Rozha One`, `Noto Sans Devanagari`, and `Noto Nastaliq Urdu`) for authentic presentation and readability.
* **RTL & LTR Support:** Native support for Right-to-Left (RTL) reading for the Urdu script and Left-to-Right (LTR) for Hindi.
* **Zero Dependencies / Lightweight:** Built with clean, standards-compliant HTML5, CSS3, and minimal vanilla JavaScript for instant loading on desktop and mobile devices.

## 🚀 Running Locally

No build tools, bundlers, or server runtimes are required.

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/](https://github.com/)anujkk/kalam-e-bedhab.git
   cd kalam-e-bedhab
   ```

2. **Open in browser:**
   Double-click `index.html` or serve using any simple local server:
   ```bash
   # Python 3
   python3 -m http.server 8000
   ```
   Then navigate to `http://localhost:8000` in your web browser.
